The `#!/usr/bin/env node` script of npm runs through the route; node then
misses its own files. A probe on the same fixture:
  node -e: fs.readFileSync('/etc/alpine-release') -> 3.24.4
  node -e: fs.statSync('/etc/alpine-release')     -> ENOENT
libuv makes `statx` a raw syscall, so no LD_PRELOAD object sees it, while
`open` goes through libc and is mapped. No TODO entry names this limit.
