# T-1700: a foreground run sometimes exits 0 with no output.
#
# Run by hand on 2026-11-10 (UTC) on the chroot-denying fixture of
# experiments/356-no-chroot-rung.sh: `unshare -Urm sh wrap.sh`, a tmpfs
# over /dev/pts, then experiments/deny-chroot.c (chroot(2) EPERM). The
# scratch store is written as $STORE, the scratch directory as $WORK.
# The image is mirror.gcr.io/library/alpine:3.20
# (sha256:d9e853e87e55526f6b2917df91a2115c36dd7c696a35be12163d44e6e2a4b6bc);
# Docker Hub and public.ecr.aws answer HTTP 429 here. static-hello:1 is a
# static-pie hello (cc -static-pie) imported with `podvm import`.
#
# BEFORE is the release binary of 4ef187e. AFTER is the same tree with
# the fix of crates/podvm/src/run/foreground.rs (untee joins the pump
# before it closes the saved stdout).
#
# Kernel 6.18.44-fc-v338, 4 CPUs, podvm 0.1.0-beta.13.

== the loop
One run: PODVM_STORE=$STORE timeout 60 unshare -Urm sh $WORK/wrap.sh $WORK \
  podvm run --rm [ARGS] IMAGE cat /etc/alpine-release >out 2>err
A run is LOST when out does not hold "3.20." (static-hello: "static-hi").
Each lost run exited 0. No run printed other output. Each run extracts
the rootfs again: --rm removes it, and no other record holds it.

Each of the 9 lost runs of that loop has the same line: the pump's write
of "3.20.10\n" to the saved stdout fails with EBADF, and its write to the
log succeeds. Four of the nine show the write as <unfinished ...> and
then `<... write resumed>) = -1 EBADF`.

== the cause
crates/podvm/src/run/foreground.rs, fn untee (4ef187e lines 100-104):

    let _ = podvm_probe::sys::dup2(tee.saved, 1);
    let _ = podvm_probe::sys::close(tee.saved);
    let _ = tee.handle.join();

The pump thread writes each byte it reads from the tee pipe to the saved
stdout (`tee.saved`), and ignores a write error. untee closed the saved
stdout before it joined the pump. When the payload wrote and exited just
before the restore, the pump read the bytes after the close: the write
failed with EBADF and the bytes went to the log only. The exit code is
the payload's own, so the run exited 0. Each foreground run takes this
path (T-1421), on each rung.

== the fix
untee restores fd 1, joins the pump, and closes the saved stdout last.
tee_stdout_to is tee_fd_to(1, ...), so a test can tee a pipe of its own.

== the test of the cause
