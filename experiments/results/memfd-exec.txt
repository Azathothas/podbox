== 2. values 1 and 2, each set in a child pid namespace
The sysctl is per pid namespace, and a child namespace may only raise it.
The drive sets it in a child of `unshare -pf`, so the host value stays 0
(the last line). Under 1, podvm passes MFD_EXEC, so the memfd executes.
Under 2, memfd_create with MFD_EXEC fails with EACCES; chroot(2) holds on
this host, so the row is a note with its fix, not a fail.
