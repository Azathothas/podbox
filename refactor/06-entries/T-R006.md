## The three-state problem this entry does not solve

⛔ **Nothing here is a Rust test, so nothing here needs a third exit state.**
That is worth saying explicitly: these 11 scripts are being removed, not ported,
so the `exit 2` question that constrains every conversion in waves 1 to 5 does not
arise here.

⛔ **A deletion is not free of the record gate.**
`scripts/check-todo.py:300` `check_tree` reads every tracked file. Any bare
`experiments/…` citation to a deleted script must be repaired in the same commit
or the gate goes red. A `sh experiments/…` reference in a `Prove` line is treated
as a command and is NOT caught — so after each deletion, grep for the bare form
and for the `sh ` form separately:

```sh
grep -rn '<script-name>' TODO/ docs/ .github/
```

## Counts

`py scripts/check-todo.py` is the only gate these touch. It proves no record
names a deleted file. It does not prove the deleted measurements were obsolete —
that is each group report's evidence, quoted above.

This entry cannot run `py scripts/check-todo.py` on a partial tree: deleting one
of these while its `Prove` line still names it is a red gate, so the deletions
and the repairs are one change each, not eleven changes.
