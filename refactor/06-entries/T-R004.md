### T-R004 Write the gate runners as one crate with six binaries

Source:      `refactor/06-entries/PLAN.md` sections 3 and 5;
             `scripts/check-todo.py:228`, `:300`; `scripts/plant.sh:51`;
             `.github/workflows/gate.yml:36-56`, `:99`, `:199`, `:213`
Category:    gate
Priority:    P1
Effort:      XL
Status:      open

Problem:     `scripts/check-todo.py` is 1,738 lines of Python, the largest script
             in the corpus, and it is the record gate: `py scripts/check-todo.py`
             runs in CI at `gate.yml:37` and every `TODO/` entry's consistency
             claim depends on it. Its siblings `todo-count.py`,
             `dev.sh`, `nightly-smoke.sh`, `plant.sh`, `session-start.sh`,
             `310-session-startup.sh`, `398-gate-diagnostics.py`,
             `build-interpose.sh` and `360-perf-harness.sh` are the same kind of
             thing in shell.
Premise:     ⭐ **The repository's dependency policy was measured, not assumed.**
             `TODO/deps.md` T-0901 through T-0911 ruled `libc`, `rustix`,
             `clap`, `goblin`, `oci-spec`, `seccompiler` and `landlock` OUT, each
             against a measurement under `experiments/results/bloat-*.txt`.
             A gate runner needs argument parsing, and `clap` is refused.
             ⭐ **The count is 13, not 11 and not 14.** `grep -rn 'scripts/plant.sh'
             TODO/*.md | grep -c 'Prove'` returns 13, across `TODO/cli.md`,
             `TODO/deps.md` and `TODO/gate.md`. The meta report gave 11 in one
             place and 14 in another for one number. ⛔ **This is the same
             failure the audit already caught twice**: a number read from the
             wrong set.
Approach:    One crate, six binaries, because the six share the row grammar and
             the exit-code contract but not their subjects. Port the pure
             parsing and matching logic first, with the file grammar extracted
             so both `podbox-gate` and `podbox-count` share it.
Decision:    ⭐ **The port is behaviour-preserving, not a redesign.** The gate
             decides what may merge. A rewrite that changes which records it
             accepts is a different task with its own review, and this entry does
             not authorise it.
             ⭐ **Arguments are parsed by hand, because `clap` was measured and
             refused** at T-0908. Do not add it.
             ⛔ **The binary paths are a single coupled change.**
             `scripts/check-todo.py:228` sets
             `CEILING_SCRIPT = "experiments/110-bloat-delta.sh"`;
             `scripts/plant.sh:51` `FILES` names the same path; and
             `gate.yml:131` runs the script. Moving `110` alone, or `plant.sh`
             alone, turns the gate red. All of the path changes land in one
             change.
             ⛔ **This entry deletes `scripts/check-todo.py`, which is its own
             `Prove` command.** That is self-referential and it is a real
             defect in the entry as written. The gate does not become
             "unprovable": `gate.yml:37` runs `./scripts/check-todo.py`, and the
             port must change that step to the new binary in the same commit.
             The `Prove` line therefore becomes:
             `./target/release/podbox-gate` exits 0, and `gate.yml:37` runs it.
             Do not leave a `Prove` that names a deleted file — and do not leave
             a `Prove` that names a file the gate no longer calls.
             ⛔ **The shared "row grammar" and exit-code contract are named but
             not specified.** Both `podbox-gate` and `podbox-count` parse
             `TODO/INDEX.md` rows and `### T-` entry headers. An implementor
             must extract those two grammars into one module and add a
             characterization test per grammar BEFORE porting any check, because
             the port is behaviour-preserving and there is otherwise no way to
             prove it preserved anything.
Prove:       ./target/release/podbox-gate

## `podbox-plant` carries two conditions in its entry

⛔ **`scripts/plant.sh` is read by the record gate.** `scripts/check-todo.py:300`
`check_tree` reads every tracked file, so the new binary's path must be recorded
in `check_tree`'s file set in the same change that moves it. A dangling path is
a red gate, not a warning.

⛔ **`gate.yml:55-56` runs it as the step named `every check can fail`.** The
workflow path must be updated in the same change. 13 `Prove:` lines across three
`TODO/` files name `scripts/plant.sh`, and each must repoint.

## `podbox-interpose-build` and the export check

⛔ **The interposer export check needs no new test and no `rlib`.**
`scripts/build-interpose.sh:197-214` already compares `nm -D` output against
`crates/podbox-interpose/interpose.map` for BOTH targets, printing
`ok: exports %s names, exactly what interpose.map declares` at `:204-205`.
`interpose.map` declares **112** names, counted with that script's own `awk` at
`:199-200`. A group report proposed adding a `tests/exported_set.rs` to
`crates/podbox-interpose`; that cannot work, because `crate-type = ["cdylib"]` at
`crates/podbox-interpose/Cargo.toml:15` yields
`error[E0433]: cannot find module or crate` in a test target. The meta review
verified this by building the minimal case.

The port keeps the existing check as the bin's logic. Check B, the `struct stat`
and `struct statx` offsets under both libcs, needs a `cc` invocation and belongs
in this binary too.

⛔ **If anyone later adds `rlib`, the cost must be named in that entry.** It adds a
release-profile artefact built for two targets on every `build-interpose.sh` run
and on `gate.yml:99`, under the byte ceiling at `scripts/build-interpose.sh:48`.
It does not disturb dependency resolution — the manifest's `[dependencies]` is
empty at `crates/podbox-interpose/Cargo.toml:18` and the crate is excluded at
`Cargo.toml:20` — but it does change the crate that ceiling measures.
