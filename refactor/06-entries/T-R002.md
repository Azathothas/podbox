## The plant requirement

`docs/conventions/code.md:32` and `TODO/gate.md`'s header rule: a check lands
with the plant that proves it can fail, in the same change. Each of the 15 tests
gets one `scripts/plant.sh` case that mutates the source to break the assertion
and shows the test going red.

`scripts/plant.sh:51` `FILES` and `scripts/check-todo.py:228` `CEILING_SCRIPT`
both name paths under `experiments/` and `scripts/`. A plant added here names
the new test's file, and `check-todo.py:300` `check_tree` reads it as a tracked
file.

## Counts

`cargo test --workspace` is the proof, plus the interposer command at
`gate.yml:213` for clauses 14 and 15. Together they prove every new test passes
and that no existing test broke.

⛔ **Neither proves the new tests can fail.** That is what the plants do, and
each plant's red run is its own evidence saved under `experiments/results/`.
A green suite with a vacuous assertion proves nothing, and
`docs/conventions/code.md:32` requires the test to reject the defect it claims
to detect.

⛔ **This entry's Prove cannot run on the Windows host.** `cargo` stops at
`linker 'cc' not found`. Run both commands on the Linux base lane with
`sh scripts/windows/run-in-base.sh`.

⛔ **The plant mechanism is not implementable as described.** `scripts/plant.sh`
operates on the paths in `FILES` at `:51`, which does not include the source
files of clauses 1 to 15. Either each plant is added to `FILES` — a change to
wave 4's subject — or the plants for this wave run as a separate script. An
implementor must choose one and record it. Note also that
`scripts/plant.sh` is itself ported in wave 4, so this wave's plants are
transitional.
Batch 0 decision, recorded 2026-10-01. D-3 takes the first option: each
wave-2 plant joins `FILES`. The dirty-tree guard then covers about twelve
more small sources, which is correct because plants run on a clean tree by
rule, and backup/restore copies those files per case. A separate script
would duplicate guards 1 through 4 and drift; wave 4 ports one harness, not
two. T-1578 implements this.
