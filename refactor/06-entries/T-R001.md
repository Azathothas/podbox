## What is deleted, and what carries each clause

### `experiments/388-interactive-shell.sh` — 11 clauses, 12 tests

Fully converted. The tests are at
`crates/podbox-ssh/tests/session_interactive.rs:255-482`.

⛔ **`TODO/podssh.md:126` does NOT name `388`.** It names `389`, `390` and
`391`. The only line naming `388` is `TODO/podssh.md:79`, and its form is:

```
Prove:       `cargo test -p podbox-ssh` exits 0; `sh experiments/388-interactive-shell.sh`
             verifies editing and interruption without a pty device.
```

⛔ **The replacement text must drop the `sh ` prefix, and that is what the gate
notices.** `scripts/check-todo.py` sees a bare `experiments/…` citation as a
tracked-file reference and a `sh experiments/…` citation as a command. Deleting
the script and leaving the `sh ` form behind leaves the gate **green** with a
`Prove` naming a file that no longer exists. Only the bare form turns it red and
catches the dangling reference. Write the line as:

```
Prove:       `cargo test -p podbox-ssh` exits 0, including
             `session_interactive` at `crates/podbox-ssh/tests/session_interactive.rs`,
             which verifies editing and interruption without a pty device.
```
