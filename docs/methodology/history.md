# History

Keep superseded evidence under `docs/history/`.
[The index](../history/README.md) gives each record's purpose.

## What to keep

Keep replaced instructions when they explain a decision.
Keep a withdrawn claim with the evidence that corrects it.
Keep research provenance, review scope, and historical measurements.
Preserve source wording when the wording itself is evidence.

A historical page does not define current behavior or the work order.
Current procedures belong in their live pages.
[Document roles](../conventions/docs.md) identify those pages.

## Corrections

Correct live text in place.
Add a correction beneath a false historical claim.
Do not silently rewrite a recorded measurement.

Do not publish private paths or credentials while saving a source record.
Use a stated path substitution when an unpublished local capture needs it.
Do not alter measured values during that conversion.

## Format

Use a dated or descriptive file name.
State its captured revision and scope.
Link it from the history index.
Link it from the live page only when it explains that page.

History is exempt from repeated-fact checks.
The character, secret, and prose checks still apply.
