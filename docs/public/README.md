# Public documents

The root README explains current use and links the operating documents.
HUMAN gives operator actions and standing decisions.
SECURITY states actual trust boundaries and report handling.
THIRD_PARTY records imported material and retained notices.
CHANGELOG records published changes.

Keep commands runnable against the current parser.
State an external program, helper, image, or host prerequisite.
Do not advertise a proposed command, isolation boundary, or future capability.

Use source-derived tables for mechanical build facts.
Use saved results for measured behavior.
Keep current limits in docs/limits.md.
Do not copy those lists into several public pages.

Keep credentials and private host paths out of examples.
Use named input arguments for host-specific files.
Do not report a skipped proof as success.

Check links from the public page to the owning document.
Keep earlier explanations in history.
The project uses the work model linked from AGENTS.md.
It does not import a second contribution or task workflow.

[document rules](../conventions/docs.md) and
[prose rules](../conventions/prose.md) apply.
